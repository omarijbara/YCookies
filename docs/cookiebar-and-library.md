# YCookies CookieBar Designer & Package Library Guide

## CookieBar Designer

The CookieBar Designer in YCookies allows you to customize the appearance, behavior, and content of the consent banner shown to your visitors.

### 1. Accessing the Designer
- Navigate to your Domain in the YCookies Admin Panel.
- Click on **Design CookieBar** from the quick actions.

### 2. Customizing Appearance
- **Colors**: Set primary, secondary, and background colors to match your brand identity.
- **Position**: Choose whether the banner appears at the bottom, top, or as a centered modal.
- **Theme**: Toggle between light and dark modes based on your website's CSS scheme.

### 3. Modifying Content
- **Text & Labels**: Update title text, description, and button labels (e.g., "Accept All", "Reject Selected").
- **Languages**: If you support multiple languages, you can define translations for each supported locale.

### 4. Advanced Settings
- **Implicit Consent**: Decide whether continued scrolling implies consent (check local regulations first).

## Package Library

The Package Library contains pre-configured blocks for popular third-party services like Google Analytics, Facebook Pixel, and more.

### 1. Browsing the Library
In the left sidebar of the Admin Panel, select **Package Library**.

### 2. Available Packages
You can browse packages by categories (Analytics, Marketing, Necessary, etc.). 
Each package includes:
- **Scripts/Iframes block configuration**: Defines exactly what needs to be blocked before consent.
- **Cookies**: The specific cookies set by the service.
- **Privacy Policy links**: Pre-filled documentation links for compliance.

### 3. Adding a Package to your Domain
1. In your Domain view, go to **Services**.
2. Click **Install from Library**.
3. Select the package you want. Any configuration required by the package (e.g., Google Analytics ID) will be prompted during installation.
